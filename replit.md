# NFELO on Replit

The public site is the static folder `site/`. There is no build step and no server code.

- **Run (preview):** serves `site/` on port 5000.
- **Deploy:** Static deployment, public directory `site`.
- **Weekly data:** a GitHub Action in this repo rebuilds `site/data/*.json` and commits it to `main`. In production the pages read that JSON straight from the GitHub repo (`raw.githubusercontent.com`), so new weeks appear without redeploying. Locally they read `site/data/`.
- **Don't edit `site/data/` by hand.** It is generated by `scripts/build.py`.
- Everything outside `site/` (Python pipeline, models, notebooks, tests) is not needed to serve the site.
